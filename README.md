## :rocket: What I Build

I turn Android phones into full Linux workstations. No cloud needed, no VPS required - just your phone, Termux, and a lot of kernel hacking.

### [Android Subsystem for Linux (ASL)](https://github.com/Ruusian/ASL)
> *Like WSL, but for Android.*

A complete Linux subsystem management engine running natively on Android. Chroot management, GPU passthrough, gaming (Box64 + Wine64 + DXVK), XFCE desktop, remote access bridges, and a GTK3 control center - all in one CLI tool.

```
Debian 13 Trixie ARM64 + Mesa Turnip Vulkan + Box64 + Wine64 + XFCE Desktop
```
